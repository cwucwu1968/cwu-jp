# cwu.jp — 生協労連ホームページ（Cloudflare Pages + GitHub）

全国生協労働組合連合会（生協労連）の公式ホームページ www.cwu.jp の移行用リポジトリ。
現行サイトは Wix。移行先は Cloudflare Pages + GitHub。

## 公開ルール（最重要）

- 更新は絶対に直接公開しない。
- 必ず下書き（プレビュー）を makabe に見せ、確認を得てから公開し、公開後に実表示を確認して報告する。
- メールが止まる事故が最重大。DNS 作業では、対象以外のレコード（特に MX・TXT・DKIM）を変更しない。

## 中身

- `index.html` — HP再現版（9セクション：トップ／私たちのこと／つくりたい社会／あなたも生協労連へ／部会／アクション／2026衆議院選挙／学習・闘争資料／お問い合わせ）。白基調＋深い赤、スマホ前提。
- `_redirects` — 旧URL→新URLの対応表（案）。フェーズ3で最終決定する。
- `PHASE1手順書.md` — リポジトリ作成から Pages 連携、pages.dev での実証までの手順。

## 含まれていないもの

- 入口ページ「学習・闘争資料」は内部資料のため、この公開リポジトリには入れていない。Muse 上のページのまま、再現版からはリンクで参照する。noindex 等は検索避けであってアクセス制御ではない。
- PDF・PPTX・動画・写真はこのリポジトリに含めていない。現行サイトへのリンクのまま。25MiB 以下のものはサイト内、超えるものは別置き（別ストレージ／YouTube）にする方針。

## デプロイ

- Cloudflare Pages のプロジェクトは、最初から GitHub 連携方式で作成すること。直接アップロードで作ると、後から Git 連携に切り替えられない。
- ビルド設定：フレームワークプリセットなし（静的サイト）、ビルドコマンドなし、出力ディレクトリはリポジトリのルート。
- 本番ドメイン（www.cwu.jp）の接続はフェーズ4まで行わない。フェーズ1〜2では pages.dev の仮アドレスでのみ確認する。

## 更新操作の実証（フェーズ1）

pages.dev で次の4種を実証する：

1. 記事の追加
2. PDF の差し替え
3. 既存記事の修正
4. 変更の取り消し（巻き戻し）

いずれもプレビュー→makabe 確認→公開のフローで回す。
